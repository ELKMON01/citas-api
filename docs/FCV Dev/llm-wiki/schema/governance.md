# Gobierno de la Wiki

## Operaciones

- INGEST: leer una fuente aprobada, incorporar solo conocimiento verificable, enlazar páginas, actualizar índice y registrar log.
- QUERY: `index.md` → páginas relevantes → fuente/código; separar evidencia de inferencia.
- LEARN: guardar únicamente conocimiento durable con clasificación HECHO, DECISIÓN, PREFERENCIA o PREGUNTA ABIERTA.
- LINT: revisar contradicciones, obsolescencia, duplicados, huérfanas, enlaces rotos, decisiones no aprobadas y contenido sensible.

RAW nunca se reescribe durante INGEST.
