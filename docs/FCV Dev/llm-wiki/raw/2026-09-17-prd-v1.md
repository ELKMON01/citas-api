# SRC-PRD-001 — PRD 1.0 (registro curado)

Procedencia: `PRD.md`, versión 1.0, consultado el 2026-09-17.

Hechos retenidos: actores USER/PROFESSIONAL/ADMIN; dos sedes fijas; registro, JWT, recuperación, afiliación, catálogos, profesionales, agenda, disponibilidad, citas generales y especializadas, cancelación, reprogramación, agenda profesional, cierre, bandeja administrativa y auditoría; REST directo entre frontend y backend. Fuera de alcance: historia clínica, facturación/pagos, diagnósticos, integraciones clínicas, SMS/WhatsApp y SMTP obligatorio.

Reglas críticas: slots de 30 minutos; duración de especialidad de 30/60; no doble reserva; generales autoaprobadas; especializadas requieren ADMIN; rechazos requieren motivo; cancelación/rechazo liberan reservas; reprogramación conserva la cita original hasta decisión; transiciones e historial son verificables.
