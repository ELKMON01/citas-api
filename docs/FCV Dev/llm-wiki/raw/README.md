# RAW

Las fuentes de esta carpeta son curadas, versionadas e inmutables. No se reescriben durante INGEST. Una revisión nueva se agrega como una fuente nueva, con procedencia y checksum en `manifest.md`.

No se almacenan secretos, tokens, credenciales ni PII real. Los documentos canónicos siguen en la raíz del workspace; estos registros conservan la selección aprobada para la memoria global.
